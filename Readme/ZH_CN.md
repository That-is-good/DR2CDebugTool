# Death Road to Canada 调试工具

基于 **Qt6** 与 C++ 开发的《加拿大死亡之路》（Death Road to Canada）游戏内存调试／修改工具。  
通过读取目标进程内存，实时显示并修改角色属性、实体状态、全局资源及武器数据，适用于游戏研究、MOD 开发或进阶玩家分析。

> **⚠️ 提示**  
> 本工具仅供学习、研究及合法调试目的，请勿用于任何违规用途。

---

## ✨ 功能特性

- **进程管理**  
  枚举系统所有进程，支持按名称或 PID 过滤，一键附加；目标进程退出时自动分离。

- **角色面板**  
  - 显示当前队伍所有角色的基本信息（姓名、特长、特质、描述）  
  - 角色下拉列表以 **★** 标记当前任务队伍成员  
  - 实时编辑 **13 项核心属性**（士气、态度、镇静、魅力等）及其基础/临时/附加值，并支持“是否已知”勾选  
  - 修改角色资源（无、食物、汽油、医疗、手枪、步枪、霰弹、垃圾 8 种）  
  - 管理 **3 个武器槽**（武器 ID、数量、锁定状态）  
  - 调整生命值、速度加成、性别、宠物标志及状态标志位

- **实体面板**（可视化图形界面）  
  - 按区域过滤实体，以图标形式展示在地图网格中  
  - 支持**选择模式**（单击/框选）、**缩放模式**（滚轮缩放）、**平移模式**（拖拽画布）  
  - 在“选择模式”下可**直接拖拽实体**到新位置（松手后写回内存）  
  - 右键菜单提供丰富操作：  
    - **设置为中心**（标记目标实体，用于后续传送/交换；中心实体会显示黄色圆圈标记）  
    - **标志**（无碰撞、隐身、不绘制、不可击中、不可拾取、发光）  
    - **修改位置/速度/物理/其他**（弹出数值调整对话框）  
    - **传送至中心**（将选中实体移至中心实体位置）  
    - **随机交换位置**（在选中实体间随机交换坐标及区域）  
    - **克隆**（复制选中实体）  
    - **销毁**（移除实体）  
    - **设为玩家实体**（将选中实体设置为当前玩家实体）  
    - **新建**（生成人类、僵尸、物品、抛射物、家具、拾取物、武器、车辆、特殊拾取）  
    - **设置渲染图层**（设置摄像机区域）  
  - 区域下拉框动态显示当前实际存在的区域

- **全局（任务）面板**  
  - 修改全局资源（8 种）  
  - 管理 **15 个仓库武器槽**（武器 ID 与数量）  
  - 脚本控制台

- **脚本控制台**  
  向游戏发送自定义脚本命令（需游戏脚本系统支持）。

- **定时刷新**  
  可自定义刷新间隔（默认 500 ms），数据自动同步更新；编辑时自动暂停刷新，避免干扰输入。

- **配置持久化**  
  所有内存偏移量、刷新频率、语言偏好等保存在 `config.json` 中，便于版本更新时快速调整。

## 📦 依赖环境

- **操作系统**：Windows（已测试 Win10/11）
- **构建工具**：  
  - CMake 3.19 或更高  
  - 支持 C++17 的编译器（MSVC 2019+ / MinGW-w64 8.0+）
- **Qt 版本**：**Qt 6.5** 或更高（必需组件：`Core`, `Widgets`, `LinguistTools`）
- **可选**：Qt Creator（推荐用于项目管理及 CMake 集成）

## 🔧 构建与运行

### 1. 获取源码
```bash
git clone https://github.com/yourusername/drtc-debug-tool.git
cd drtc-debug-tool
```

### 2. 使用 Qt Creator（推荐）
- 打开 Qt Creator，选择 **“打开项目”**，定位到 `CMakeLists.txt`。
- 选择 Qt 6.5+ 的编译套件（如 `Desktop Qt 6.5.0 MinGW 64-bit`）。
- 点击 **“构建”**（或按 Ctrl+B），生成的可执行文件位于 `build/` 下的子目录中。
- 构建完成后，可在 `build/Release/` 或 `build/` 下找到 `DR2CDebugTool.exe`。

### 3. 部署与运行
- 直接运行 `DR2CDebugTool.exe`（若缺少 Qt 动态库，需将 Qt 的 `bin` 目录加入 PATH，或使用 `windeployqt` 部署）。
- 首次运行会自动生成 `config.json`（如不存在）。

## 📖 使用指南

### 启动与附加进程
1. 运行工具，主窗口顶部显示进程列表。  
2. 在过滤框中输入进程名（例如 `prog`）或 PID，按回车筛选。  
3. 从下拉列表中选择游戏进程（通常为 `prog.exe`）。  
4. 点击 **“附加”**，状态栏会显示附加成功及模块基址。  
5. 工具开始自动刷新数据，界面控件启用。

### 设置内存偏移
若游戏更新导致数据读取失效，点击 **“设置”** 按钮打开偏移对话框：  
- 分别配置**角色**、**实体**、**武器**、**全局**的起始偏移、结构大小和最大数量。  
- 调整全局刷新间隔（毫秒）。  
- 切换界面语言（可选“系统”或所有已加载的翻译文件；当前包含中文、英文、日语，可自行扩展），需重启生效。
- 保存后立即生效，无需重启。

### 角色操作
- 在 **“角色”** 选项卡中，从下拉列表选择一名角色。  
- 所有可编辑字段（文本框、数值框、复选框）均支持直接修改，提交后自动写入内存。  
- 属性表格中的“基础/临时/附加”列可双击编辑，有效值会自动计算。注意“临时”值通常由状态标志控制，手动修改意义不大。  
- “是否已知”列可勾选，用于修改角色属性是否已知。  
- 武器槽点击按钮可弹出武器选择对话框，从已读取的武器列表中选择。  
- 修改状态标志（属性1/属性2）时，建议按二进制位理解其含义。

### 实体操作（可视化视图）
- 在 **“实体”** 选项卡中，首先通过“区域”下拉框筛选感兴趣的区域（默认“全部”）。  
- 视图右上角提供三种交互模式：  
  - **选择**（默认）：可单击或框选实体，选中后可在右键菜单中操作，也可直接拖拽移动。  
  - **缩放**：滚动滚轮缩放视图，适合查看整体布局。  
  - **移动**：拖拽平移画布，方便浏览大范围区域。  
- 右键单击任一实体（或空白区域）弹出上下文菜单：  
  - 若选中多个实体，多数操作会作用于全部选中项。  
  - **“设置为中心”**：标记一个实体作为目标（后续传送/交换以此为基准），中心实体会显示黄色圆圈标记。  
  - **“标志”**子菜单：批量开启/关闭特殊属性（无碰撞、隐身等）。显示的标志状态是所有选中实体的逻辑与结果。  
  - **“修改位置/速度/物理/其他”**：弹出对话框精确调整数值。对话框中显示的是第一个选中实体的当前值。  
  - **“传送至中心”**：将选中实体移动到中心实体坐标。  
  - **“随机交换”**：在选中实体之间随机互换位置（包括区域）。  
  - **“克隆”**：在当前位置复制一份选中实体（若类型支持）。  
  - **“销毁”**：彻底移除实体。  
  - **“设为玩家实体”**：将选中实体设置为当前玩家实体。  
  - **“新建”**子菜单：在鼠标位置生成新实体（类型可选）。  
    > **注意**：生成 **物品、抛射物、家具、拾取物、武器、车辆、特殊拾取** 等非角色实体时，通常需要额外设置 **精灵图（Sprite ID）**，否则该实体在游戏中不会正确显示。请在“修改其他”对话框中为新建实体指定有效的精灵图 ID。  
  - **“设置渲染图层”**：将当前区域设置为摄像机的渲染目标。例如，当玩家操控的角色跨区域传送后，需调用此功能将新区域设为渲染图层，否则摄像头可能卡在左上角。  
- 拖拽实体时，自动暂停刷新，松手后写回新坐标并恢复刷新；多选拖拽同样适用。

### 全局（任务）操作
- **“全局”** 选项卡显示全局资源及仓库武器。  
- 角色面板下拉列表以 **★** 标记当前队伍成员，成员名自动同步自角色数据。  
- 资源表格可直接编辑数量，编辑后点击表格触发写入。  
- 仓库武器槽以按钮+数量微调框组合形式排列，点击按钮选择武器 ID，微调框调整数量（范围 0-999）。

### 脚本控制台
- 在“全局”选项卡底部的命令输入框中，输入游戏内脚本命令（如 `spawn`），按回车发送。  
- 由于游戏支持 UTF-8，命令中可包含 Unicode 字符（游戏自带的控制台无法输入此类字符）。  
- 执行结果（成功/失败）会在状态栏提示。

## 🗂 项目结构

| 文件/目录 | 说明 |
|-----------|------|
| `mainwindow.cpp/.h/.ui` | 主窗口 UI 及逻辑，包含所有信号/槽、数据刷新和修改操作 |
| `Setting/addrsetting.cpp/.h/.ui` | 偏移量设置对话框，管理配置读写 |
| `Memory/memorymanager.cpp/.h` | 进程枚举、附加/分离、内存读写、实体分配/释放等底层封装 |
| `Memory/gamedatareader.cpp/.h` | 根据偏移读取/写入游戏数据结构（角色、实体、全局状态等） |
| `Delegates/spinboxdelegate.cpp/.h` | 为表格提供 QSpinBox 编辑器委托 |
| `WeaponDialog/weapondialog.cpp/.h` | 武器选择对话框，展示已加载的武器名称列表 |
| `Languages/` | Qt 翻译文件（`.ts`，支持英语、中文、日语） |
| `Struct/` | 逆向分析得到的游戏数据结构体定义（`thing`, `character`, `mission_state` 等） |
| `config.json` | 自动生成/读取的配置文件，存储偏移量、刷新间隔、语言等 |
| `CMakeLists.txt` | CMake 项目主配置文件 |

## ⚠️ 注意事项

- **游戏版本兼容性**：偏移量可能随游戏更新而变化。若数据异常，请使用“设置”功能更新偏移（可通过 Cheat Engine 等工具重新定位）。  
- **稳定性**：内存修改存在崩溃风险，建议提前备份存档。若游戏崩溃，重新启动游戏即可，工具无需重开。  
- **编辑冲突**：在编辑字段时，自动刷新会暂停，避免因数据覆盖导致输入中断。但请勿同时使用其他内存修改工具，以免竞争。  
- **只读用途**：若仅需查看数据，避免误触修改字段；工具默认将任何 UI 变化即时写入内存。  
- **语言支持**：界面语言从 translations 目录动态加载，支持系统语言及所有可用翻译文件（当前已包含中文、英文、日语），可在设置中自由切换，并允许用户添加自定义翻译。  
- **销毁实体 vs 删除角色**：在实体面板中执行 **“销毁”** 仅会移除游戏世界中的实体对象（如角色模型、物品模型等），**并不会**释放该实体所绑定的角色数据（角色槽位）。
