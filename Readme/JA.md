# Death Road to Canada デバッグツール

**Qt6** と C++ で開発された『Death Road to Canada』（カナダ死亡ロード）のゲームメモリデバッグ／改造ツールです。  
対象プロセスのメモリを読み取り、キャラクター属性、エンティティ状態、グローバルリソース、武器データをリアルタイムで表示・変更します。ゲーム研究、MOD 開発、上級プレイヤーの分析に適しています。

> **⚠️ 注意**  
> 本ツールは学習・研究および合法的なデバッグ目的のみに使用してください。いかなる不正用途にも使用しないでください。

---

## ✨ 機能

- **プロセス管理**  
  システム上の全プロセスを列挙し、名前または PID によるフィルタリングに対応。ワンクリックでアタッチ。対象プロセス終了時は自動的にデタッチします。

- **キャラクターパネル**  
  - 現在のパーティ全キャラクターの基本情報（名前、パーク、特性、説明）を表示  
  - キャラクターのドロップダウンリストでは、現在のミッションのパーティメンバーに **★** マークを表示  
  - **13 種類のコア属性**（士気、態度、冷静さ、魅力など）の基礎値／一時値／追加値をリアルタイムで編集し、「既知かどうか」のチェックにも対応  
  - キャラクターリソース（なし、食料、ガソリン、医療、拳銃、ライフル、散弾銃、ジャンクの 8 種類）を変更  
  - **3 つの武器スロット**（武器 ID、数量、ロック状態）を管理  
  - HP、速度ボーナス、性別、ペットフラグ、状態フラグを調整

- **エンティティパネル**（可視化ビュー）  
  - エリアごとにエンティティをフィルタリングし、マップグリッド上にアイコンで表示  
  - **選択モード**（クリック／範囲選択）、**ズームモード**（ホイールズーム）、**パンモード**（キャンバスドラッグ）に対応  
  - 「選択モード」ではエンティティを**直接ドラッグ**して新しい位置に移動できます（マウスを離すとメモリに書き戻し）  
  - 右クリックメニューには豊富な操作があります：  
    - **中心に設定**（対象エンティティをマークし、以降のテレポート／交換の基準にします。中心エンティティには黄色い円マーカーが表示されます）  
    - **フラグ**（衝突なし、ステルス、非描画、被弾不可、拾得不可、発光）  
    - **位置／速度／物理／その他を変更**（数値調整ダイアログを表示）  
    - **中心へテレポート**（選択したエンティティを中心エンティティの座標へ移動）  
    - **位置をランダム交換**（選択したエンティティ間で座標とエリアをランダムに入れ替え）  
    - **クローン**（選択したエンティティを複製）  
    - **破壊**（エンティティを削除）  
    - **プレイヤーエンティティに設定**（選択したエンティティを現在のプレイヤーエンティティに設定）  
    - **新規作成**（人間、ゾンビ、アイテム、投射物、家具、拾得物、武器、車両、特殊拾得物を生成）  
    - **レンダリングレイヤーを設定**（カメラエリアを設定）  
  - エリアのドロップダウンには現在実際に存在するエリアが動的に表示されます

- **グローバル（ミッション）パネル**  
  - グローバルリソース（8 種類）を変更  
  - **15 個の倉庫武器スロット**（武器 ID と数量）を管理  
  - スクリプトコンソール

- **スクリプトコンソール**  
  ゲームにカスタムスクリプトコマンドを送信（ゲームのスクリプトシステムの対応が必要）。

- **定期リフレッシュ**  
  リフレッシュ間隔をカスタマイズ可能（既定 500 ms）。データは自動で同期更新されます。編集中は自動的にリフレッシュを一時停止し、入力の妨げを防ぎます。

- **設定の永続化**  
  すべてのメモリオフセット、リフレッシュ頻度、言語設定などは `config.json` に保存され、バージョン更新時に素早く調整できます。

## 📦 必要環境

- **OS**：Windows（Win10/11 でテスト済み）
- **ビルドツール**：  
  - CMake 3.19 以上  
  - C++17 対応コンパイラ（MSVC 2019+ / MinGW-w64 8.0+）
- **Qt バージョン**：**Qt 6.5** 以上（必須コンポーネント：`Core`, `Widgets`, `LinguistTools`）
- **任意**：Qt Creator（プロジェクト管理および CMake 連携に推奨）

## 🔧 ビルドと実行

### 1. ソースの取得
- ソースzipをダウンロードする

### 2. Qt Creator を使用する（推奨）
- Qt Creator を開き、**「プロジェクトを開く」** を選択して `CMakeLists.txt` を指定します。
- Qt 6.5+ のキット（例：`Desktop Qt 6.5.0 MinGW 64-bit`）を選択します。
- **「ビルド」** をクリック（または Ctrl+B）。生成された実行ファイルは `build/` 以下のサブディレクトリにあります。
- ビルド完了後、`build/Release/` または `build/` 以下に `DR2CDebugTool.exe` があります。

### 3. デプロイと実行
- `DR2CDebugTool.exe` を直接実行します（Qt の動的ライブラリが不足している場合は、Qt の `bin` ディレクトリを PATH に追加するか、`windeployqt` でデプロイしてください）。
- 初回実行時に `config.json` が自動生成されます（存在しない場合）。

## 📖 使用ガイド

### 起動とプロセスのアタッチ
1. ツールを起動すると、メインウィンドウ上部にプロセス一覧が表示されます。  
2. フィルタ欄にプロセス名（例：`prog`）または PID を入力し、Enter で絞り込みます。  
3. ドロップダウンリストからゲームのプロセス（通常は `prog.exe`）を選択します。  
4. **「アタッチ」** をクリックすると、ステータスバーにアタッチ成功とモジュールベースアドレスが表示されます。  
5. ツールはデータの自動リフレッシュを開始し、UI コントロールが有効になります。

### メモリオフセットの設定
ゲームの更新でデータ読み取りが機能しなくなった場合は、**「設定」** ボタンをクリックしてオフセットダイアログを開きます：  
- **キャラクター**、**エンティティ**、**武器**、**グローバル** の開始オフセット、構造体サイズ、最大数を個別に設定します。  
- 全体のリフレッシュ間隔（ミリ秒）を調整します。  
- UI 言語を切り替えます（「システム」または読み込まれたすべての翻訳ファイルから選択可能。現在は中国語、英語、日本語を含み、独自に拡張できます）。反映には再起動が必要です。
- 保存後はすぐに反映され、再起動は不要です。

### キャラクター操作
- **「キャラクター」** タブで、ドロップダウンリストからキャラクターを選択します。  
- すべての編集可能フィールド（テキストボックス、数値ボックス、チェックボックス）は直接変更でき、確定後に自動でメモリへ書き込まれます。  
- 属性テーブルの「基礎値／一時値／追加値」列はダブルクリックで編集でき、有効値は自動計算されます。「一時値」は通常ステータスフラグによって制御されるため、手動で変更してもあまり意味はありません。  
- 「既知かどうか」列はチェック可能で、キャラクター属性が既知かどうかを変更できます。  
- 武器スロットのボタンをクリックすると武器選択ダイアログが開き、読み込まれた武器リストから選択できます。  
- 状態フラグ（属性1／属性2）を変更する際は、ビット単位で意味を理解することをおすすめします。

### エンティティ操作（可視化ビュー）
- **「エンティティ」** タブで、まず「エリア」ドロップダウンから目的のエリアを絞り込みます（既定は「すべて」）。  
- ビュー右上に 3 つの操作モードがあります：  
  - **選択**（既定）：クリックまたは範囲選択でエンティティを選べます。選択後は右クリックメニューで操作でき、直接ドラッグして移動もできます。  
  - **ズーム**：ホイールでビューを拡大縮小します。全体配置の確認に適しています。  
  - **移動**：キャンバスをドラッグして平行移動します。広範囲の閲覧に便利です。  
- エンティティ（または空白領域）を右クリックするとコンテキストメニューが表示されます：  
  - 複数のエンティティを選択している場合、ほとんどの操作は選択項目すべてに適用されます。  
  - **「中心に設定」**：エンティティをターゲットとしてマークします（以降のテレポート／交換の基準）。中心エンティティには黄色い円マーカーが表示されます。  
  - **「フラグ」** サブメニュー：特殊属性（衝突なし、ステルスなど）を一括でオン／オフします。表示されるフラグ状態は、選択した全エンティティの論理積です。  
  - **「位置／速度／物理／その他を変更」**：ダイアログで数値を正確に調整します。ダイアログには最初に選択したエンティティの現在値が表示されます。  
  - **「中心へテレポート」**：選択したエンティティを中心エンティティの座標へ移動します。  
  - **「ランダム交換」**：選択したエンティティ間で位置（エリアを含む）をランダムに入れ替えます。  
  - **「クローン」**：現在位置に選択したエンティティを複製します（タイプが対応している場合）。  
  - **「破壊」**：エンティティを完全に削除します。  
  - **「プレイヤーエンティティに設定」**：選択したエンティティを現在のプレイヤーエンティティに設定します。  
  - **「新規作成」** サブメニュー：マウス位置に新しいエンティティを生成します（タイプ選択可）。  
    > **注意**：**アイテム、投射物、家具、拾得物、武器、車両、特殊拾得物** など非キャラクターエンティティを生成する場合、通常は追加で **スプライト（Sprite ID）** を設定する必要があります。設定しないと、そのエンティティはゲーム内で正しく表示されません。「その他を変更」ダイアログで、新規エンティティに有効なスプライト ID を指定してください。  
  - **「レンダリングレイヤーを設定」**：現在のエリアをカメラのレンダリングターゲットに設定します。たとえば、プレイヤーが操作するキャラクターを別エリアへテレポートさせた後、この機能で新しいエリアをレンダリングレイヤーに設定しないと、カメラが左上に固定されたままになることがあります。  
- エンティティをドラッグしている間は自動的にリフレッシュが一時停止し、マウスを離すと新しい座標が書き戻されてリフレッシュが再開されます。複数選択のドラッグにも対応しています。

### グローバル（ミッション）操作
- **「グローバル」** タブにはグローバルリソースと倉庫武器が表示されます。  
- キャラクターパネルのドロップダウンリストでは、現在のパーティメンバーに **★** マークが表示され、メンバー名はキャラクターデータから自動同期されます。  
- リソーステーブルは数量を直接編集でき、編集後にテーブルをクリックすると書き込みが実行されます。  
- 倉庫武器スロットはボタン＋数量スピンボックスの組み合わせで並んでいます。ボタンをクリックして武器 ID を選択し、スピンボックスで数量を調整します（範囲 0〜999）。

### スクリプトコンソール
- 「グローバル」タブ下部のコマンド入力欄に、ゲーム内スクリプトコマンド（例：`spawn`）を入力し、Enter で送信します。  
- ゲームは UTF-8 に対応しているため、コマンドに Unicode 文字を含めることができます（ゲーム内蔵のコンソールではこのような文字を入力できません）。  
- 実行結果（成功／失敗）はステータスバーに表示されます。

## 🗂 プロジェクト構成

| ファイル／ディレクトリ | 説明 |
|-----------|------|
| `mainwindow.cpp/.h/.ui` | メインウィンドウの UI とロジック。すべてのシグナル／スロット、データリフレッシュ、変更操作を含む |
| `Setting/addrsetting.cpp/.h/.ui` | オフセット設定ダイアログ。設定の読み書きを管理 |
| `Memory/memorymanager.cpp/.h` | プロセス列挙、アタッチ／デタッチ、メモリ読み書き、エンティティの割り当て／解放などの低レベルラッパー |
| `Memory/gamedatareader.cpp/.h` | オフセットに基づいてゲームデータ構造（キャラクター、エンティティ、グローバル状態など）を読み書き |
| `Delegates/spinboxdelegate.cpp/.h` | テーブルに QSpinBox エディタを提供するデリゲート |
| `WeaponDialog/weapondialog.cpp/.h` | 武器選択ダイアログ。読み込まれた武器名リストを表示 |
| `Languages/` | Qt 翻訳ファイル（`.ts`、英語・中国語・日本語に対応） |
| `Struct/` | リバースエンジニアリングで得られたゲームデータ構造体定義（`thing`, `character`, `mission_state` など） |
| `config.json` | 自動生成／読み込みされる設定ファイル。オフセット、リフレッシュ間隔、言語などを保存 |
| `CMakeLists.txt` | CMake プロジェクトのメイン設定ファイル |

## ⚠️ 注意事項

- **ゲームバージョン互換性**：オフセットはゲームの更新によって変化する可能性があります。データが異常な場合は、「設定」機能でオフセットを更新してください（Cheat Engine などのツールで再特定できます）。  
- **安定性**：メモリ変更にはクラッシュのリスクがあります。事前にセーブデータをバックアップすることをおすすめします。ゲームがクラッシュした場合は、ゲームを再起動すればよく、ツールを再起動する必要はありません。  
- **編集の競合**：フィールド編集中は、データ上書きによる入力中断を防ぐため、自動リフレッシュが一時停止します。ただし、競合を避けるため、他のメモリ変更ツールを同時に使用しないでください。  
- **閲覧専用用途**：データを閲覧するだけの場合は、誤って変更フィールドに触れないようにしてください。ツールは既定で、UI の変更を即座にメモリへ書き込みます。  
- **言語サポート**：UI 言語は translations ディレクトリから動的に読み込まれ、システム言語および利用可能なすべての翻訳ファイル（現在は中国語、英語、日本語を含む）に対応します。設定で自由に切り替えられ、ユーザーがカスタム翻訳を追加することも可能です。  
- **エンティティの破壊 vs キャラクターの削除**：エンティティパネルで「破壊」を実行すると、ゲーム世界内のエンティティオブジェクト（キャラクターモデル、アイテムモデルなど）のみが削除され、そのエンティティに紐づくキャラクターデータ（キャラクタースロット）は**解放されません**。
