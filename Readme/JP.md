# Death Road to Canada デバッグツール

**Death Road to Canada** のゲームプロセスメモリをリアルタイムに読み書きするデバッグ／編集ツールです。  
**Qt6** と C++ で開発されており、キャラクター属性、エンティティ状態、グローバルリソース、武器データなどを画面上で直接変更できます。ゲーム研究、MOD 開発、上級プレイヤーの解析に役立ちます。

> **⚠️ 重要なお知らせ**  
> 本ツールは学習・研究・正当なデバッグ目的のみに使用してください。他ユーザーのゲーム体験を妨害したり、不正な目的で使用することは固くお断りします。

---

## ✨ 主な機能

- **プロセス管理**  
  システム上の全プロセスを一覧表示し、名前や PID でフィルタリング。対象プロセスにワンクリックでアタッチ／デタッチ可能。

- **キャラクターパネル**  
  - 現在のパーティーに属する全キャラクターの基本情報（名前、特技、特徴、説明）を表示  
  - **13 種類の基本ステータス**（士気、態度、冷静さ、魅力など）および基本値／一時値／ボーナス値をリアルタイム編集  
  - リソース（食料、ガソリン、医療品、弾薬など 8 種類）の編集  
  - 所持する **3 つの武器スロット**（武器 ID、スタック数、ロック状態）の管理  
  - 体力、速度ボーナス、性別、ペットフラグ、および 2 つの状態フラグ（ビットマスク）の変更

- **エンティティパネル（グラフィカルビュー）**  
  - エリア単位でフィルタリングし、アイコンでマップ上に表示  
  - 3 つの操作モード：**選択**（クリック／範囲選択）、**拡大縮小**（ホイール）、**移動**（ドラッグでキャンバスをパン）  
  - *選択モード*では、エンティティを**ドラッグ＆ドロップ**で移動可能（ドロップ時にメモリへ書き戻し）  
  - 右クリックコンテキストメニューが充実：  
    - **ターゲット設定** – 基準となるエンティティをマーク（テレポート／交換用）  
    - **フラグ** – 無衝突、不可視（敵視認不可）、描画非表示、被弾無効、拾得不可、発光 を一括トグル（複数選択時は全対象に適用）  
    - **位置／速度／物理／その他を編集** – 数値調整ダイアログを表示  
    - **ターゲットへテレポート** – 選択エンティティをターゲット座標へ移動  
    - **ランダム交換** – 選択エンティティ同士で座標とエリアをランダムにシャッフル  
    - **クローン** – 選択エンティティを複製（対応タイプのみ）  
    - **破棄** – エンティティをゲームから削除  
    - **新規作成** – マウス位置に新エンティティを生成（人間、ゾンビ、アイテム、投射物、家具、拾得物、武器、乗り物、特殊拾得 から選択）

- **ミッション（グローバル）パネル**  
  - 現在のパーティメンバーを表示（キャラクター名と自動連携）  
  - グローバルリソース（8 種類）を編集  
  - **15 個の倉庫武器スロット**（武器 ID と数量）を管理

- **スクリプトコンソール**  
  ゲーム内スクリプトシステムにカスタムコマンドを送信可能。

- **自動更新**  
  更新間隔をカスタマイズ可能（デフォルト 500 ms）。編集中は自動更新を一時停止し、入力の競合を回避。

- **設定の永続化**  
  すべてのメモリオフセット、更新頻度、言語設定は `config.json` に保存。ゲームバージョン更新時にも容易に調整可能。

## 📦 必要条件

- **OS**: Windows（10/11 で動作確認）
- **ビルドツール**:  
  - CMake 3.19 以上  
  - C++17 対応コンパイラ（MSVC 2019+ / MinGW-w64 8.0+）
- **Qt バージョン**: **Qt 6.5** 以上（必須コンポーネント: `Core`, `Widgets`, `LinguistTools`）
- **オプション**: Qt Creator（プロジェクト管理・CMake 統合に推奨）

## 🔧 ビルドと実行

### 1. ソースコードを取得
```bash
git clone https://github.com/yourusername/drtc-debug-tool.git
cd drtc-debug-tool
```

### 2. Qt Creator を使用（推奨）
- Qt Creator を起動し、「プロジェクトを開く」からプロジェクトルートの `CMakeLists.txt` を選択。
- Qt 6.5+ のキット（例: `Desktop Qt 6.5.0 MinGW 64-bit`）を選択。
- 「ビルド」（Ctrl+B）をクリック。実行ファイルは `build/` 配下のサブフォルダに生成されます。
- ビルド後、`build/Release/` または `build/` に `DR2CDebugTool.exe` が生成されます。

### 3. デプロイと実行
- `DR2CDebugTool.exe` を直接実行（Qt DLL が不足する場合は、Qt の `bin` ディレクトリを PATH に追加するか、`windeployqt` を使用）。
- 初回起動時、`config.json` が自動生成されます（存在しない場合）。

## 📖 使い方

### 起動とプロセスへのアタッチ
1. ツールを起動すると、プロセス一覧が表示されます。  
2. フィルタボックスにプロセス名（例: `prog`）や PID を入力し Enter キーを押すと絞り込み可能。  
3. ドロップダウンリストからゲームプロセス（通常 `prog.exe`）を選択。  
4. **「アタッチ」** ボタンをクリック。ステータスバーにアタッチ成功とモジュールベースアドレスが表示されます。  
5. 自動更新が始まり、UI コントロールが有効になります。

### メモリオフセットの設定
ゲームアップデートでデータが正しく読み取れなくなった場合は、**「設定」** ボタンをクリックしてオフセットダイアログを開きます。  
- **キャラクター**、**エンティティ**、**武器**、**ミッション** それぞれの開始オフセット、構造体サイズ、最大数を設定。  
- 更新間隔（ミリ秒）を調整。  
- UI 言語（システム、英語、中文、日本語）を選択（再起動必要）。  
- 保存すると即座に反映され、再起動不要です。

### キャラクター操作
- **「キャラクター」** タブで、ドロップダウンリストからキャラクターを選択。  
- 編集可能なフィールド（テキストボックス、スピンボックス、チェックボックス）は直接変更可能。変更は即座にメモリへ書き込まれます。  
- ステータステーブルの「基本値／一時値／ボーナス値」はダブルクリックで編集可能。有効値は自動計算されます。  
- 武器スロットのボタンをクリックすると武器選択ダイアログが開き、読み込まれた武器リストから選択できます。  
- 2 つの状態フラグ（属性1／属性2）は整数ビットマスクとして扱います（バイナリ演算で操作）。

### エンティティ操作（グラフィカルビュー）
- **「エンティティ」** タブで、上部のエリアコンボボックスを利用して特定マップエリアのエンティティのみ表示可能（デフォルトは「すべて」）。  
- 右上のラジオボタンで 3 つの操作モードを切り替え：  
  - **選択**（デフォルト）：クリックまたはドラッグで範囲選択。選択したエンティティは**ドラッグで移動**でき、ドロップ時に新しい座標がメモリへ書き戻されます。  
  - **拡大縮小**：マウスホイールでビューを拡大／縮小。  
  - **移動**：キャンバスをドラッグしてパン。  
- エンティティ上（または空白部分）で右クリックするとコンテキストメニューが表示されます：  
  - 複数選択時は、ほとんどの操作が全選択エンティティに適用されます。  
  - **「ターゲット設定」**：クリックしたエンティティをターゲットとしてマーク（ボタンがハイライト）。テレポート／交換の基準として使用。  
  - **「フラグ」**サブメニュー：選択中のエンティティに対して、無衝突、不可視（敵視認不可）、描画非表示、被弾無効、拾得不可、発光 を一括でオン／オフ。  
  - **「位置／速度／物理／その他を編集」**：数値調整ダイアログを開き、精密な設定が可能。  
  - **「ターゲットへテレポート」**：選択エンティティをターゲットエンティティの座標へ移動。  
  - **「ランダム交換」**：選択エンティティ同士で座標とエリアをランダムに入れ替え。  
  - **「クローン」**：選択エンティティを複製（対応タイプのみ）。  
  - **「破棄」**：選択エンティティをゲームから削除。  
  - **「新規作成」**サブメニュー：マウス位置に新エンティティを生成（人間、ゾンビ、アイテム、投射物、家具、拾得物、武器、乗り物、特殊拾得 から選択）。  
- ドラッグ中は自動更新が一時停止され、ドラッグ終了後に再開されます（シーン再構築による干渉を防止）。

### ミッション（グローバル）操作
- **「ミッション」** タブでは、パーティメンバー、グローバルリソース、倉庫武器が表示されます。  
- メンバー名はキャラクターリストと自動連携され、読み取り専用です。  
- リソースの数値はテーブル上で直接編集可能。  
- 倉庫武器スロットはボタン＋スピンボックスのグリッド形式で表示。ボタンをクリックして武器 ID を選択し、スピンボックスで数量を調整します。

### スクリプトコンソール
- 「ミッション」タブの右下にある入力フィールドにゲームスクリプトコマンド（例: `spawn`）を入力し Enter キーを押します。  
- 実行結果（成功／失敗）がステータスバーに表示されます。

## 🗂 プロジェクト構成

| ファイル／ディレクトリ | 説明 |
|------------------------|------|
| `mainwindow.cpp/.h/.ui` | メインウィンドウの UI とロジック – 全シグナル/スロット、データ更新、変更処理 |
| `Setting/addrsetting.cpp/.h/.ui` | オフセット設定ダイアログ – オフセット管理および設定ファイルの読み書き |
| `Memory/memorymanager.cpp/.h` | プロセス列挙、アタッチ/デタッチ、メモリ読み書き、エンティティ割り当て/解放などの低レベル処理 |
| `Memory/gamedatareader.cpp/.h` | オフセットを用いてゲームデータを読み取り、高レベル構造体（キャラクター／エンティティ／ミッション）に変換 |
| `Delegates/spinboxdelegate.cpp/.h` | テーブルセル用の QSpinBox エディタデリゲート |
| `WeaponDialog/weapondialog.cpp/.h` | 武器選択ダイアログ（読み込まれた武器名一覧を表示） |
| `Languages/` | Qt 翻訳ファイル（`.ts`、英語・中国語・日本語対応） |
| `Struct/` | リバースエンジニアリングで得られたゲームデータ構造体定義（`thing`, `character`, `mission_state` など） |
| `config.json` | オフセットやユーザー設定を保存する自動生成／読み込み設定ファイル |
| `CMakeLists.txt` | CMake プロジェクトメイン設定ファイル |

## ⚠️ 注意事項

- **ゲームバージョンの互換性**：オフセットは特定バージョンに依存します。データが正常に表示されない場合は、**設定**ダイアログからオフセットを更新してください（Cheat Engine 等で再調査可能）。  
- **安定性**：メモリ編集はクラッシュのリスクを伴います。セーブデータのバックアップを推奨します。ゲームがクラッシュした場合は再起動するだけでよく、ツール自体は再起動不要です。  
- **編集競合**：フィールド編集中は自動更新が一時停止され、入力が上書きされるのを防ぎます。ただし、他のメモリ編集ツールを同時に使用しないでください（競合の原因となります）。  
- **読み取り専用モード**：データ参照のみの場合は編集を避けてください。本ツールは UI 変更を即座にメモリへ書き込みます。  
- **言語サポート**：UI は日本語・中国語・英語に対応（設定ダイアログで切り替え）。
