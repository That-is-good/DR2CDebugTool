# Death Road to Canada 调试工具

本项目是《加拿大死亡之路》（Death Road to Canada）游戏的辅助调试/内存修改工具，基于 **Qt6** 和 C++ 开发。通过读取游戏进程内存，实时显示并修改角色属性、实体状态、队伍资源及物品数据，方便游戏研究者、MOD 开发者或进阶玩家进行数据分析和调试。

> **⚠️ 重要提示**  
> 本工具仅用于学习、研究及合法调试目的。

---

## ✨ 功能特性

- **进程管理**  
  列出系统所有进程，按名称或 PID 过滤，一键附加/分离目标进程。

- **角色面板**  
  - 显示当前队伍所有角色的基本信息（姓名、特长、特质、描述等）  
  - 实时查看并修改角色的 **13 项基础属性**（士气、态度、镇静、魅力等）以及临时/附加属性  
  - 编辑角色资源（食物、汽油、医疗、弹药等 8 种）  
  - 管理角色携带的 **3 个武器槽**（武器 ID、数量、锁定状态）  
  - 修改生命值、速度加成、性别、宠物标志及状态标志位

- **实体面板**  
  - 按类型（人类/僵尸/物品/抛射物等）和区域过滤实体列表  
  - 查看实体详细信息：位置、速度、物理参数、AI 状态、精灵 ID、血量等  
  - 支持实时修改实体坐标、速度、质量、摩擦系数、碰撞/可见性标志等  
  - 实体操作：**设置目标**（用于传送/交换）、**传送至目标**、**交换位置**、**销毁实体**  
  - **生成实体**（支持人类、僵尸、各类物品/武器/家具等）

- **任务（Mission）面板**  
  - 显示当前队伍成员（自动关联角色名称）  
  - 修改全局资源（食物、汽油、医疗等 8 种）  
  - 管理 **15 个仓库武器槽**（武器 ID 与数量）

- **脚本控制台**  
  支持向游戏发送自定义脚本命令（需游戏内脚本系统支持）。

- **定时刷新**  
  可自定义刷新频率（默认 500ms），数据自动同步显示。

- **配置持久化**  
  所有内存偏移量、更新频率、语言偏好等保存为 `config.json` 文件，便于不同游戏版本切换。

## 📦 依赖环境

- **操作系统**：Windows
- **构建工具**：
  - CMake 3.19 或更高版本
  - 支持 C++17 的编译器（MSVC 2019+ / MinGW-w64 8.0+）
- **Qt 版本**：**Qt 6.5** 或更高（必需组件：`Core`, `Widgets`, `LinguistTools`）
- **可选**：Qt Creator（推荐用于项目管理及 CMake 集成）

---

## 🔧 构建与运行

### 1. 获取源码
```bash
git clone https://github.com/yourusername/drtc-debug-tool.git
cd drtc-debug-tool
```

### 2. 使用 Qt Creator（推荐）
- 打开 Qt Creator，选择 **“打开项目”**，定位到项目根目录下的 `CMakeLists.txt`。
- 选择 Qt 6.5+ 的编译套件（如 `Desktop Qt 6.5.0 MinGW 64-bit`）。
- 点击 **“构建”**（或按 Ctrl+B），生成的可执行文件位于 `build/` 目录下的对应子文件夹。

构建完成后，可在 `build/Release/` 或 `build/` 下找到 `DR2CDebugTool.exe`。

### 3. 运行与部署
- 直接运行可执行文件（可能需要将 Qt 动态库路径加入 PATH，或使用 `windeployqt` 部署）。

## 📖 使用指南

### 启动与附加进程
1. 运行工具，主窗口显示进程列表（可输入进程名或 PID 过滤）。
2. 从下拉列表中选择游戏进程（通常是 `prog.exe`）。
3. 点击 **“附加进程”**，状态栏显示附加成功及模块基址。
4. 工具开始自动刷新数据，界面控件启用。

### 设置内存偏移
若游戏版本更新导致数据读取失效，点击 **“设置”** 按钮打开地址偏移对话框：
- 分别配置 **角色**、**实体**、**武器**、**任务** 的起始偏移、结构大小和最大数量。
- 调整全局更新频率（毫秒）。
- 语言选项（支持系统、英文、中文、日语），需重启。
- 保存后自动生效，无需重启。

### 角色操作
- 在 **“角色”** 选项卡中，从下拉列表选择一名角色。
- 所有可编辑字段均支持直接修改（按 Enter 键或切换焦点提交）。
- 属性表格中的“基础/临时/附加”值可双击编辑，有效值自动计算。
- 武器槽点击按钮弹出武器选择对话框，从已读取的武器列表中选取。

### 实体操作
- 在 **“实体”** 选项卡，通过类型/区域过滤列表，单击选中实体。
- 右侧面板显示该实体的详细数据，可实时修改。
- **设置目标**：将当前选中实体设为目标（按钮高亮），后续可执行传送或交换位置。
- **生成实体**：在生成下拉框中选择类型，点击“生成”按钮，新实体将出现在当前地图（坐标随机）。

### 任务操作
- **“任务”** 选项卡显示当前队伍成员、全局资源和仓库武器。
- 成员名字自动匹配角色列表，不可编辑。
- 资源数量可直接修改，武器槽同样通过按钮选择武器 ID，数量可调。

#### 脚本控制台
- 在底部输入框输入游戏脚本命令（例如 `spawn` 等），按回车发送。
- 执行结果将在状态栏提示（成功/失败）。

## 🗂 文件结构说明

| 文件/目录 | 说明 |
|-----------|------|
| `mainwindow.cpp/.h/.ui` | 主窗口 UI 及逻辑，所有信号/槽、数据刷新、修改操作 |
| `Setting/addrsetting.cpp/.h/.ui` | 地址设置对话框，管理偏移量及配置读写 |
| `Memory/memorymanager.cpp/.h` | 进程枚举、附加/分离、内存读写、实体分配/释放等底层操作 |
| `Memory/gamedatareader.cpp/.h` | 根据偏移读取游戏数据，转换为高层结构（角色/实体/任务等） |
| `Delegates/spinboxdelegate.cpp/.h` | 表格内 QSpinBox 编辑器委托 |
| `WeaponDialog/weapondialog.cpp/.h` | 武器选择对话框 |
| `Languages/` | Qt 翻译文件（`.ts`，支持中/英/日） |
| `Struct` | 逆向分析得到的游戏数据结构体定义（`thing`, `character`, `weapon`, `mission_state` 等） |
| `config.json` | 自动生成/读取的配置文件，存储偏移量和用户设置 |
| `CMakeLists.txt` | CMake 项目主配置文件 |

## ⚠️ 注意事项

- **游戏版本兼容性**：本工具基于特定游戏版本逆向，偏移量可能随游戏更新而变化。若数据异常，请使用“设置”功能更新偏移（可通过 CE 等工具重新定位）。
- **稳定性**：内存修改存在崩溃风险，建议提前备份存档。若游戏闪退，重新启动游戏即可。
- **只读模式**：若仅需查看数据，可避免修改字段；但工具默认将任何 UI 变化即时写入内存，请注意操作。
- **语言支持**：界面支持中/英/日切换。
