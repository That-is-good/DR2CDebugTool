# Death Road to Canada デバッグツール

本ツールは、ゲーム『Death Road to Canada』（デス・ロード・トゥ・カナダ）のデバッグ／メモリ編集ツールです。**Qt6** と C++ で開発されており、ゲームプロセスのメモリを読み取ることで、キャラクターのステータス、エンティティの状態、パーティーリソース、アイテムデータなどをリアルタイムに表示・変更できます。ゲーム研究者、MOD開発者、あるいは上級プレイヤーの解析・デバッグに役立ちます。

> **⚠️ 重要なお知らせ**  
> 本ツールは学習・研究・正当なデバッグ目的のみに使用してください。

---

## ✨ 主な機能

- **プロセス管理**  
  システム上の全プロセスを一覧表示し、名前やPIDでフィルタリング。対象プロセスにワンクリックでアタッチ／デタッチ可能。

- **キャラクターパネル**  
  - 現在のパーティーに属する全キャラクターの基本情報（名前、特技、特徴、説明など）を表示  
  - **13種類の基本ステータス**（士気、態度、冷静さ、魅力など）および一時・ボーナス値をリアルタイムで表示・編集  
  - リソース（食料、ガソリン、医療品、弾薬など8種類）の編集  
  - 所持する **3つの武器スロット**（武器ID、スタック数、ロック状態）の管理  
  - 体力、速度ボーナス、性別、ペットフラグ、状態フラグの変更

- **エンティティパネル**  
  - タイプ（人間／ゾンビ／アイテム／投射物など）やエリアでフィルタリング  
  - エンティティの詳細情報（位置、速度、物理パラメータ、AI状態、スプライトID、HPなど）を表示  
  - 座標、速度、質量、摩擦係数、衝突／可視性フラグなどをリアルタイムで変更  
  - エンティティ操作：**ターゲット設定**（テレポート／交換用）、**ターゲットへテレポート**、**位置交換**、**エンティティ破棄**  
  - **エンティティ生成**（人間、ゾンビ、各種アイテム／武器／家具など）

- **ミッションパネル**  
  - 現在のパーティーメンバーを表示（キャラクター名と自動連携）  
  - グローバルリソース（食料、ガソリン、医療品など8種類）の編集  
  - **15個の倉庫武器スロット**（武器IDと数量）の管理

- **スクリプトコンソール**  
  ゲーム内スクリプトシステムに対し、カスタムコマンドを送信可能。

- **自動更新**  
  更新間隔をカスタマイズ可能（デフォルト500ms）、データは自動的に同期。

- **設定の永続化**  
  すべてのメモリオフセット、更新頻度、言語設定は `config.json` に保存され、ゲームバージョンが変わっても容易に切り替え可能。

## 📦 必要条件

- **OS**: Windows
- **ビルドツール**:
  - CMake 3.19 以上
  - C++17 対応コンパイラ（MSVC 2019+ / MinGW-w64 8.0+）
- **Qt バージョン**: **Qt 6.5** 以上（必須コンポーネント: `Core`, `Widgets`, `LinguistTools`）
- **オプション**: Qt Creator（プロジェクト管理およびCMake統合に推奨）

## 🔧 ビルドと実行

### 1. ソースコードを取得
```bash
git clone https://github.com/yourusername/drtc-debug-tool.git
cd drtc-debug-tool
```

### 2. Qt Creator を使用（推奨）
- Qt Creator を起動し、「プロジェクトを開く」からプロジェクトルートの `CMakeLists.txt` を選択。
- Qt 6.5+ のキット（例: `Desktop Qt 6.5.0 MinGW 64-bit`）を選択。
- 「ビルド」（Ctrl+B）をクリック。実行ファイルは `build/` 配下のサブフォルダに生成されます。

ビルド後、`build/Release/` または `build/` に `DR2CDebugTool.exe` が生成されます。

### 3. 実行とデプロイ
- 生成された実行ファイルを直接起動（必要に応じてQt DLLへのパスを通すか、`windeployqt` を使用）。

## 📖 使い方

### 起動とプロセスへのアタッチ
1. ツールを起動すると、プロセス一覧が表示されます（名前またはPIDでフィルタリング可能）。
2. ドロップダウンリストからゲームプロセス（通常 `prog.exe`）を選択。
3. **「アタッチ」** ボタンをクリック。ステータスバーにアタッチ成功とモジュールベースアドレスが表示されます。
4. 自動更新が始まり、UIコントロールが有効になります。

### メモリオフセットの設定
ゲームアップデートでデータが正しく読み取れなくなった場合は、**「設定」** ボタンをクリックしてオフセットダイアログを開きます。
- **キャラクター**、**エンティティ**、**武器**、**ミッション** それぞれの開始オフセット、構造体サイズ、最大数を設定。
- 更新間隔（ミリ秒）を調整。
- UI言語（システム、英語、中文、日本語）を選択、再起動必要です。
- 保存すると即座に反映され、再起動は不要です。

### キャラクター操作
- **「キャラクター」** タブで、ドロップダウンリストからキャラクターを選択。
- 編集可能なフィールドは直接変更可能（Enterキーまたはフォーカスを外すと反映）。
- ステータステーブルの「基本/一時/ボーナス」値はダブルクリックで編集可能。有効値は自動計算されます。
- 武器スロットのボタンをクリックすると武器選択ダイアログが開き、読み込まれた武器リストから選択できます。

### エンティティ操作
- **「エンティティ」** タブで、タイプやエリアでフィルタリングし、一覧からエンティティをクリックして選択。
- 右側パネルに詳細データが表示され、リアルタイムに編集可能。
- **「ターゲット設定」**：現在選択中のエンティティをターゲットとしてマーク（ボタンがハイライト）。その後、テレポートや位置交換が実行できます。
- **「エンティティ生成」**：生成コンボボックスでタイプを選び「生成」をクリックすると、現在のマップ（ランダム座標）に新エンティティが出現します。

### ミッション操作
- **「ミッション」** タブでは、現在のパーティーメンバー、グローバルリソース、倉庫武器が表示されます。
- メンバー名はキャラクター名と自動連携され、読み取り専用です。
- リソース値は直接編集可能。倉庫武器スロットもボタンで武器IDを選択し、数量はスピンボックスで調整します。

#### スクリプトコンソール
- 下部の入力フィールドにゲームスクリプトコマンド（例: `spawn`）を入力し、Enterキーを押します。
- ステータスバーに実行結果（成功/失敗）が表示されます。

## 🗂 プロジェクト構成

| ファイル／ディレクトリ | 説明 |
|------------------------|------|
| `mainwindow.cpp/.h/.ui` | メインウィンドウのUIとロジック – 全シグナル/スロット、データ更新、変更処理 |
| `Setting/addrsetting.cpp/.h/.ui` | オフセット設定ダイアログ – オフセット管理および設定ファイルの読み書き |
| `Memory/memorymanager.cpp/.h` | プロセス列挙、アタッチ/デタッチ、メモリ読み書き、エンティティ割り当て/解放などの低レベル処理 |
| `Memory/gamedatareader.cpp/.h` | オフセットを用いてゲームデータを読み取り、高レベル構造体（キャラクター/エンティティ/ミッション）に変換 |
| `Delegates/spinboxdelegate.cpp/.h` | テーブルセル用のQSpinBoxエディタデリゲート |
| `WeaponDialog/weapondialog.cpp/.h` | 武器選択ダイアログ |
| `Languages/` | Qt翻訳ファイル（`.ts`、英語・中国語・日本語対応） |
| `Struct` | リバースエンジニアリングで得られたゲームデータ構造体定義（`thing`, `character`, `weapon`, `mission_state` など） |
| `config.json` | オフセットやユーザー設定を保存する自動生成/読み込み設定ファイル |
| `CMakeLists.txt` | CMakeプロジェクトメイン設定ファイル |

## ⚠️ 注意事項

- **ゲームバージョンの互換性**：本ツールは特定のゲームバージョンを元にリバースエンジニアリングされています。ゲームアップデートによりオフセットが変わる場合があります。データが正常に表示されない場合は、**設定**ダイアログからオフセットを更新してください（Cheat Engine等で再調査可能）。
- **安定性**：メモリ編集はクラッシュのリスクを伴います。セーブデータのバックアップを推奨します。ゲームがクラッシュした場合は再起動してください。
- **読み取り専用モード**：データの参照のみを行う場合は編集を避けてください。ただし、本ツールはUIの変更を即座にメモリに書き込むため、操作には注意してください。
- **言語サポート**：UIは日本語・中国語・英語に対応しています。
